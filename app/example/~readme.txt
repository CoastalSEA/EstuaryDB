The example folders include:

../
archive_file_format.txt - file with header text for an estuary archive file with explanation of content (see Appendix F in manual)
EDB_default_DSproperties.xlsx - definitions of the DSproperties for the estuary property tables used in EstuaryDB (Tidal Levels, River Flows, Classification, Gross Properties).

../Table data
Sample_mat_import.mat - matlab table of the JNCC estuary data for the UK
Sample_text_import.txt - sub-set of UK estuary database with type, range, volumes and areas (same as Sample_Excel_import.xlsx)
Sample_Excel_import.xlsx - sub-set of UK estuary database with type, range, volumes and areas (same as Sample_text_import.txt)
Sample_DSproperties.xlsx - file to load DSproperties for the Sample import files (use JNCC option when loading the mat file)

Estuary_Inlet_tables.xlsx - UK data and classification
Estuary_Inlet_DSproperties.xlsx - file to load DSproperties for the properties used in UK_Estuary_Inlet db.xlsx

../Spatial data
PooleSubsampled.txt - xyz file of bathymetry grid for Poole harbour
Poole_sample estuary_properties.xlsx - classification, tide and river properties for Poole harbour (use EDB_default_DSproperties.xlsx to define the DSproperties)
Sample surface area (a) hypsometry.xlsx - example of surface area hypsometry import file using format (a) (see Appendix D in manual)
Sample surface area (b) hypsometry.xlsx - example of surface area hypsometry import file using format (b) (see Appendix D in manual)
Sample_width_hypsometry.xlsx - example of width hypsometry import file (see Appendix D in manual)
